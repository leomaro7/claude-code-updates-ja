# Claude Code v2.1.258 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-258

## 💡 注目ポイント

### 1. macOS 12 (Monterey) での起動失敗の修正

バージョン 2.1.255 で導入された回帰により、macOS 12 (Monterey) で Claude Code が起動できない問題を修正しました。これにより、macOS 12 ユーザーは再び正常にアプリケーションを使用できるようになります。

### 2. リモートおよびスケジュールされたセッションのエラー修正

再送された許可承認が適用できなかった場合に発生する「ユーザーメッセージには空でないコンテンツが必要です」というエラーを修正しました。これにより、リモートおよびスケジュールされたセッションが正しく機能するようになります。
