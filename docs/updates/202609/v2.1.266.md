# Claude Code v2.1.266 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-266

## 💡 注目ポイント

### 1. LLM-gateway と proxy 設定のバグ修正

2.1.265 で導入された regression により、`CLAUDE_CODE_USE_GATEWAY` 環境変数が `ANTHROPIC_BASE_URL` と `ANTHROPIC_AUTH_TOKEN` が両方設定されていない場合でも Cloud-gateway へのサインインを強制するようになってしまいました。このバージョンでは、この変数単独では無視されるよう修正され、設定変更は不要です。
