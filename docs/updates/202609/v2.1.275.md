# Claude Code v2.1.275 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-275

## 💡 注目ポイント

### 1. サインインアカウントの追加と確認

Claude apps gateway のサインイン時に、サインインアカウントが追加され、クレデンシャルが保存される前に確認するようになりました。また、`/status` コマンドでサインインアカウントが表示されるようになりました。

### 2. 送信キーの追加

Ctrl+Enter または Ctrl+X Ctrl+S で現在のターンを中断し、キューに溜まったメッセージを一度に送信できるようになりました。送信されたメッセージとキューに溜まったメッセージは、モデルが受信するまで灰色で表示されます。

### 3. スキルとプラグインの同期

claude.ai アカウントで有効化されているスキルとプラグインが、ターミナルセッションに同期されるようになりました。`syncClaudeAiSkills: false` または `syncClaudeAiPlugins: false` でオプトアウトできます。

### 4. プラグインのインストールコマンドの改善

`/plugin install <plugin> --marketplace <source>` コマンドが追加され、プラグインをインストールする前にマーケットプレイスを追加するオプションが提供されるようになりました。

### 5. VS Code エクステンションの改善

VS Code エクステンションにおいて、メモリの表示・編集・削除、添付画像の送信、MCP サーバーの再試行リンク、プロポーザル変更タブでの変更ごとの受け入れ・拒否ボタンの追加、および複数のバグ修正が行われた。
