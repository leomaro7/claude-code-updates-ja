# Claude Code v2.1.277 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-277

## 💡 注目ポイント

### 1. AGENTS.md サポートの追加

プロジェクトに `CLAUDE.md` がない場合、Claude Code は `AGENTS.md` を読み込むようになりました。これは `/config` の「プロジェクトの指示」で変更できます（Bedrock、Vertex、Foundry ではまだ利用できません）。

### 2. `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` の追加

Claude アプリのゲートウェイがフォワードプロキシのみを外部接続先とする場合に、すべての外部リクエストがプロキシにホスト名を渡すようになりました（ローカルで解決されなくなりました）。

### 3. ゲートウェイアップストリームに静的ヘッダーを送信するオプションの追加

Claude アプリのゲートウェイアップストリームに `headers:` マップを追加し、プロバイダーの前に実行しているプロキシに静的ヘッダーを送信できるようになりました。

## 📋 変更一覧

### ✨ 新機能

| 変更 | 誰にどう嬉しいか |
|---|---|
| AGENTS.md サポートの追加 | プロジェクトに `CLAUDE.md` がない場合でも、エージェントの設定を `AGENTS.md` で管理できる |
| `CLAUDE_GATEWAY_PROXY_IS_EGRESS_BOUNDARY=1` の追加 | フォワードプロキシのみを外部接続先とするゲートウェイの設定が簡素化される |
| ゲートウェイアップストリームに静的ヘッダーを送信するオプションの追加 | プロキシに静的ヘッダーを送信できるようになる |

### ⬆️ 改善

| 変更 | 誰にどう嬉しいか |
|---|---|
| プロンプト処理の改善 | プロンプトに含まれる不可視の Unicode フォーマット文字やタグ文字が除去され、クリーンなプロンプトが送信前に表示される |
| `/ultrareview` の改善 | レビューする内容がない場合、状況に応じたメッセージが表示され、最新のコミットをレビューするコマンドが提案される |

### 🐛 バグ修正

| 変更 | 誰にどう嬉しいか |
|---|---|
| `claude -p` と Agent SDK セッションが内部エラー後にハングする問題を修正 | エラーが報告され、コード 1 で終了するようになる |
| 空のテキストブロックを含むアシスタントのターン後に会話が失敗する問題を修正 | 会話が正常に進行するようになる |
| 古い Claude Code ビルドが実行されている場合に予期せずログアウトされる問題を修正 | セッションが正常に維持されるようになる |
| その他多数のバグ修正 | 安定性と使いやすさが向上 |
