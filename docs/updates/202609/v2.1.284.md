# Claude Code v2.1.284 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-284

## 💡 注目ポイント

### 1. Claude Sonnet 5.5 の追加

新しいモデル `claude-sonnet-5-5` が Anthropic API のデフォルト Sonnet モデルになりました。1M のコンテキストを持ち、料金は $2/$10 パー Mtok で、キャッシュ読み取りは $0.20/Mtok です。

### 2. 作業ディレクトリ外の読み取り許可オプションの追加

自動モードのプロンプトに「Yes, but ask again next time」の回答を追加しました。これにより、作業ディレクトリ外の読み取りを一度許可しても、次回からは再度確認を求めることができます。

### 3. 使用量制限の通知改善

使用量制限の通知が、`/usage` コマンドとステータスラインに表示されるようになりました。また、`rate_limits.spend_limit` に `used_usd`、`limit_usd`、`period` が追加されました。

### 4. `/effort` スライダーのキーバインディング追加

`effortSlider:decreaseEffort`、`increaseEffort`、`toggleUltracode` のキーバインディングアクションが追加され、`/effort` スライダーの矢印キーと Tab キーを `keybindings.json` で再バインドできるようになりました。

### 5. `/rate-limit-options` コマンドの追加

`claude.ai` サブスクライバー向けに、`/help` とコマンドメニューに `/rate-limit-options` が追加されました。これにより、使用量制限の通知が指すコマンドを見つけやすくなりました。
