# Claude Code v2.1.257 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-257

## 💡 注目ポイント

### 1. Claude Fable 5.1 の追加

新たなデフォルト Fable モデルとして、1M のコンテキストと $10/$50 の Mtok あたりの料金、および $0.25/Mtok のキャッシュ読み取り料金で提供されます。より高度な自然言語処理が可能となり、より複雑なタスクにも対応できるようになります。

### 2. タイムフォーマットとタイムゾーン設定の追加

`timeFormat` と `timeZone` 設定により、ターン終了時のクロックとトランスクリプトビューのタイムスタンプを 12 時間制、24 時間制、24 時間制 UTC、または strftime パターンで表示できるようになりました。ユーザーの地域や好みに合わせて時間表示をカスタマイズできます。

### 3. Contain Escape ルールの追加

クラウドメタデータクレデンシャルの取得、外部への回避、およびテナント間の到達が自動承認されなくなり、環境が期待されるものとしてマークしていない限り、自動モードでこれらのアクションは承認されません。セキュリティ強化に貢献します。

### 4. `/effort` コマンドのセッション限定オプション追加

`/effort` コマンドに `s` オプションを追加し、現在のセッションのみに effort を変更できるようになりました。これにより、一時的なタスクに合わせて effort を調整できます。

### 5. 自動モードでのファイル読み取り警告の追加

自動モードで作業ディレクトリ外のファイルを初めて読み取る前に、一度だけ警告が表示され、そのような読み取りをブロックするオプション (`permissions.blockReadsOutsideWorkingDirectories`) が提供されます。セキュリティとプライバシーを強化します。
