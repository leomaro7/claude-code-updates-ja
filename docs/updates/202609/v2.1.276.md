# Claude Code v2.1.276 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-276

## 💡 注目ポイント

### 1. プロキシやゲートウェイを介したリクエストの失敗を修正

以前のバージョン（2.1.275）で発生していた、`ANTHROPIC_BASE_URL` がプロキシやゲートウェイを指している場合に `400 … Input tag 'advisor_20260301'` エラーですべてのリクエストが失敗する問題を修正しました。これにより、プロキシやゲートウェイを介したリクエストが正常に行われるようになりました。
