# Claude Code v2.1.259 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-259

## 💡 注目ポイント

### 1. `managedMcpServers` マネージド設定の追加 — 組織がユーザーごとに HTTP/SSE MCP サーバーを提供可能

組織は `.mcp.json` と同じ形式で HTTP/SSE MCP サーバーをユーザーごとに提供できるようになりました。コマンドを実行するエントリーはスキップされます。

### 2. `--permission-prompts none` オプションの追加 — 無人ヘッドレスホスト向けの自動許可拒否

無人ヘッドレスホスト向けに、プロンプトを表示するようなものは自動的に拒否されるようになりました。アクティブな許可モード（自動モードを含む）は引き続き決定します。

### 3. GitLab マージリクエストの認識 — ツールサマリーとフッターバッジの更新

`glab mr create/merge/close/reopen/note/update` コマンドが認識されるようになり、GitLab マージリクエストは折りたたまれたツールサマリーに `MR!N` として表示され、フッターMRバッジが更新されます。

### 4. `claude plugin validate` に `--json` オプションの追加 — 機械可読な検証レポートの生成

`claude plugin validate` コマンドに `--json` オプションが追加され、機械可読な検証レポートを生成できるようになりました。

### 5. バグ修正の多数 — 安定性とパフォーマンスの向上

複数のバグ修正により、安定性とパフォーマンスが向上しました。具体的には、同時セッションでの `~/.claude.json` の変更が上書きされないようになり、Bash `Read()` の拒否ルールが改善されました。
