# Claude Code v2.1.273 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-273

## 💡 注目ポイント

### 1. LLM ゲートウェイ向けリクエストヘッダーの追加

`x-claude-code-request-class`, `x-claude-code-agent-type`, `x-claude-code-prev-tool-durations`, `x-claude-code-compaction`, `x-claude-code-context-compacted` のヘッダーが追加されました。これらは `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` で有効化できます。

### 2. セッションのフォーキング機能

`claude --remote-control` または `/remote-control` で開始したセッションをフォークできるようになりました。フォークはバックグラウンドセッションとしてユーザーのコンピューター上で実行されます。

### 3. クラウドセッションの自動再接続と通知

MCP サーバーがセッション中に切断された場合、自動再接続が失敗した際に `/mcp` を指す通知が表示されます。

### 4. バグ修正と改善

多数のバグ修正と改善が行われました。例えば、Bash コマンドの権限チェック、スキルの同期、設定の無視、エラーメッセージの改善などが含まれます。

### 5. クラウドセッションと VSCode の改善

クラウドセッションと VSCode でのエラーメッセージの改善、ネットワークパスの権限チェックの改善、routine ページの改善などが実施されました。
