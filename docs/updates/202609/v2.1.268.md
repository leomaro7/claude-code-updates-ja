# Claude Code v2.1.268 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-268

## 💡 注目ポイント

### 1. ゲートウェイの課金レート管理の改善

`gateway.yaml` に `pricing:` を設定することで、サインインした Claude Code クライアントは管理された設定を通じて同じレートを受け取れるようになりました。これにより `/cost` とテレメトリは支出メーターと一致します。

### 2. ゲートウェイのアクセス制御の強化

`access_control.allow_cidrs` が空の場合、ゲートウェイの起動時に警告が表示されるようになりました。また、パブリックアドレスからの最初のリクエスト時に一度だけ警告が表示されます。

### 3. セッション状態の削除オプションの追加

`claude self-hosted-runner --remove-session-state`（デフォルトはオフ）により、セッション終了時に各セッションのディレクトリを `<base-dir>/_sessions/` 以下から削除できるようになりました。

### 4. WebFetch のタイムアウト設定

WebFetch がサーバーの応答を待ち続ける問題を修正し、300秒後にフェッチが失敗するようにしました。`CLAUDE_CODE_WEBFETCH_DEADLINE_MS` で期限をオーバーライドできます（0 で無効）。

### 5. 高 CPU 使用率の修正

長時間アイドル状態のセッションで CPU コアを占有していたバジーループを修正し、セッションの再開中に急速なターミナルフォーカスレポートが CPU を高負荷に保つ問題を解決しました。
