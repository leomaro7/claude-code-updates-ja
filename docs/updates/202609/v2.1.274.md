# Claude Code v2.1.274 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-274

## 💡 注目ポイント

### 1. メモリ使用量がクリティカルな状態になった際の警告表示

メモリ使用量がクリティカルな状態になった際に、メモリを解放する方法や安全に再起動する方法を示す警告が表示されるようになった。これまではメモリ不足によるクラッシュや不安定な動作に直面することがあったが、この変更によりユーザーは事前に警告を受け、適切な処置を講じることができる。

### 2. クラウドセッションでの diff ビューに「比較対象ブランチ」ピッカーを追加

クラウドセッションの diff ビューに「比較対象ブランチ」ピッカーが追加され、ベースブランチだけでなく任意のブランチと比較できるようになった。これにより、コードレビューや変更の確認がより柔軟に行えるようになった。

### 3. VS Code エクステンションの改善

VS Code エクステンションにおいて、継続性の向上、設定メニューの追加、エディターグループのロック解除設定の追加、および複数のバグ修正が行われた。これらの改善により、VS Code での Claude Code の使い勝手が向上した。

### 4. Claude Tag の改善とバグ修正

Claude Tag において、ゲスト設定の追加、Slack でのメッセージ受信と返信の改善、Slack 検索の修正、安全フィルターの動作の改善、メールアドレスの表示形式の修正、Enterprise Grid チャンネルの監視の修正、環境ピッカーの修正、ライブ進捗チェックリストの改善などが行われた。これらの変更により、Claude Tag の機能と安定性が向上した。

### 5. Code Review の改善

Code Review において、再レビュー時の不具合の修正、一時的なエラー発生時の再試行の追加、投稿される検出事項の表現の改善、組織制限によるスキップ時のカードと PR コメントの改善が行われた。これらの改善により、Code Review の品質とユーザーエクスペリエンスが向上した。
