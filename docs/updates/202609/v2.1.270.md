# Claude Code v2.1.270 アップデートまとめ

## 💡 注目ポイント

### 1. 読み取り専用の Git コマンドで予期せぬ許可要求が発生する問題を修正

Bash で読み取り専用の Git コマンドを実行する際、セッションが一定時間経過した後に予期せぬ許可要求が発生する問題が修正されました。この問題は 2.1.269 で導入された回帰バグでした。
