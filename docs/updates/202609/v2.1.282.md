# Claude Code v2.1.282 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-282

## 💡 注目ポイント

### 1. `maxProseWidth` 設定の追加 — 広いターミナルでのプローズ幅を制限

広いターミナルでクラウドのプローズ幅を制限する `maxProseWidth` 設定が追加されました。テーブルやコードブロックはフル幅を維持します。これまで広いターミナルでプローズが読みにくかった課題を解決します。

### 2. `/status` と `claude doctor` のテレメトリー変数リストの追加

プロジェクトの設定ファイルで無視されたり、テレメトリーをオフにするテレメトリー変数をリストアップする `/status` と `claude doctor` エントリが追加されました。テレメトリー設定の確認が容易になります。

### 3. `/feedback` ドラフトリストにスクロールバーの追加

フルスクリーンモードでマウスがリストの上にいる間、`/feedback` ドラフトリストにスクロールバーが表示されるようになりました。長いリストのスクロールが容易になります。

### 4. セッションの再開時のエラー修正

セッションの再開時に発生していた様々なエラーが修正されました。これにより、セッションの再開がより安定し、ユーザーエクスペリエンスが向上します。

### 5. クラウドセッションの改善

クラウドセッションの様々な改善が行われました。GitHub Appのステータス表示、リポジトリメニューのリンク追加、Routinesページの読み込み速度向上などが含まれます。これらの改善により、クラウドセッションの使い勝手が向上します。
