# Claude Code v2.1.260 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-260

## 💡 注目ポイント

### 1. フルスクリーンモードでの差分パネルの追加

フルスクリーンモードで会話の横に差分パネルを開き、Claude が編集する未コミット変更を表示します。`/diff` でトグルできます。

```mermaid
flowchart LR
    A[フルスクリーンモード] -->|/diff| B[差分パネル]
```

### 2. プロンプトキャッシュミスの原因の追加

`/cost` とステータスラインの `prompt_cache` フィールドに、プロンプトキャッシュミスの可能性のある原因（例：ツール定義やシステムプロンプトの変更、TTLを超えてアイドル状態）を追加しました。

### 3. `/reload-plugins` の追加

ヘッドレスセッションに `/reload-plugins` を追加し、Claude Code Desktop と SDK コマンドリストに表示されるようになりました。

### 4. `/advisor` のテキスト形式の追加

デスクトップアプリ、リモートコントロール、その他のヘッドレス（`-p`/Agent SDK）セッションに `/advisor` のテキスト形式（`/advisor`、`/advisor <model>`、`/advisor off`）を追加しました。

### 5. バグ修正の多数

複数のバグ修正により、安定性とパフォーマンスが向上しました。具体的には、Bash サンドボックスによるパーセンテージを含むパスの `Edit`/`Write`/`Read` 権限ルールのドロップ、Bash 権限チェックによる zsh コマンドの自動承認、Bedrock モデルの発見、トークンカウント、AWS SSO/STS クレデンシャル呼び出しの失敗など。
