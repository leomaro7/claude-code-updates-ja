# Claude Code v2.1.267 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-267

## 💡 注目ポイント

### 1. `maxEffortLevel` 設定の追加

`maxEffortLevel` 設定が追加されました。これはトップレベルまたは `modelSettings` の下の各モデルに対して、Bedrock、Vertex、Foundry を含むすべてのプロバイダーの努力レベルを制限します。ユーザーは依然としてより低いレベルを選択できます。

### 2. `--system-prompt-snapshot off` の追加

`--system-prompt-snapshot off` が追加され、会話の記録されたプロンプトを再利用するのではなく、毎回リクエストに対してシステムプロンプトを新しくレンダリングします（プロンプトテキストの反復のため）。

### 3. `/context` およびその他のローカルコマンドの出力がモバイルクライアントで空白になる問題の修正

`/context` およびその他のローカルコマンドの出力がモバイルクライアントで空白になる問題が修正されました。

### 4. クラウドでの Cowork スケジュールされたタスクが、サンドボックスを必要とする組織の管理設定を持つ場合に起動時に失敗する問題の修正

クラウドでの Cowork スケジュールされたタスクが、サンドボックスを必要とする組織の管理設定を持つ場合に起動時に失敗する問題が修正されました。
