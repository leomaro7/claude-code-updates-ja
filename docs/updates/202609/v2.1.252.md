# Claude Code v2.1.252 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-252

## 💡 注目ポイント

### 1. Bash コマンドの安定性向上 — Mac ユーザーの作業効率を改善

一部の Mac で発生していた "task output swap refused (tasks dir moved or linked)" エラーが修正されました。このエラーは特定のディレクトリ構造やリンク設定下で Bash コマンドの実行に失敗する問題でした。修正により、Mac ユーザーがより安定して Bash コマンドを利用できるようになりました。

### 2. プロジェクト設定の保存問題の修正 — 初期設定が不要なプロジェクトでの設定保存が可能に

`.claude/settings.local.json` ファイルが存在しないプロジェクトで "always allow" 設定が保存されない問題が修正されました。これにより、新規プロジェクトでもシームレスに設定を保存できるようになりました。

### 3. Remote Control セッションの安定性向上 — 接続不良時のスタックを解消

Claude Desktop や VS Code でホストされる Remote Control セッションが、`claude.ai` への接続が不安定な状況下でツールの実行後に数分間スタックする問題が修正されました。これにより、接続環境が悪くてもセッションが正常に進行するようになりました。
