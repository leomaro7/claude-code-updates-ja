# Claude Code v2.1.269 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-269

## 💡 注目ポイント

### 1. `claude plugin eval` コマンドの追加 — プラグインの評価スイートを実行し、スコア付きの再現可能な結果を取得

プラグインの評価スイートを Claude Code に対して実行し、JSON と HTML レポートで結果を取得できるようになりました。詳細は `claude plugin eval --help` を参照してください。

### 2. `/output-style [name]` コマンドの追加 — 出力スタイルの一覧表示と切り替え

出力スタイルの一覧表示と切り替えが可能になりました。Remote Control やクラウド、その他のヘッドレスセッションでも使用できます。

### 3. Bash ツールによるファイル編集時の diff 表示 — ファイル編集を扱う Bash ツールの結果に変更されたファイルの diff を追加

`bashEditDiffEnabled` 設定を有効にすると、Bash ツールがファイル編集を扱う際に、変更されたファイルの diff が表示されます。

### 4. `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS` の追加 — Workflow ツールの同時エージェント制限を上げる

1 から 256 までの範囲で Workflow ツールの同時エージェント制限を上げることができます。

### 5. `/ultrareview --post` の変更 — PR コメントを直接投稿し、コメントリンクを表示

findings が到着した時点で PR コメントを直接投稿し、コメントリンクを表示するよう変更されました。

```mermaid
flowchart LR
    Findings[Findings arrive] --> Post[Post PR comment directly]
    Post --> Print[Print comment link]
```
