# Claude Code v2.1.299 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-299

## 💡 注目ポイント

### 1. アイドル状態での会話圧縮機能

長時間アイドル状態にある大規模な会話（200K+ トークン）が約54分間放置された場合、1時間のプロンプトキャッシュが期限切れになる前に圧縮されます。これにより、次のメッセージで会話全体を再処理する必要がなくなります。

```mermaid
flowchart LR
    A["200K+ トークンの会話"] --> B["54分間アイドル"]
    B --> C["圧縮"]
    C --> D["プロンプトキャッシュ期限切れ"]
```

### 2. ファイルメンションの改善

`CLAUDE_CODE_DISABLE_FILE_MENTIONS` 環境変数を追加し、Claude が `@` ファイルメンションのパスを読み取るようになりました。これにより、ファイルの内容ではなくパスを取得できるようになりました。

### 3. プラグイン評価時のツール制限

`--disallow-tools` と `disallowed_tools` ケースフィールドを `claude plugin eval` に追加し、特定の組み込みツール（Agent など）を評価実行から除外できるようになりました。

### 4. スキルプロンプトの改善

モッドの `skill.prompt` フックが受け取る情報に、スキルのフロントマター、ソース、プラグイン名、ファイルパスを追加しました。

### 5. エージェントビューの改善

`/effort` と `/fast` をエージェントビューに追加し、新しいセッションの開始設定を設定できるようになりました。また、`/model`、`/effort`、`/fast` を単独で入力すると、ピッカーが開くようになりました。

## 📋 変更一覧

### ✨ 新機能

| 変更 | 誰にどう嬉しいか |
|---|---|
| `CLAUDE_CODE_DISABLE_FILE_MENTIONS` 環境変数を追加 | ファイルの内容ではなくパスを取得できる |
| アイドル状態での会話圧縮機能を追加 | 次のメッセージで会話全体を再処理する必要がなくなる |
| `--disallow-tools` と `disallowed_tools` ケースフィールドを `claude plugin eval` に追加 | 特定の組み込みツールを評価実行から除外できる |
| モッドの `skill.prompt` フックが受け取る情報に、スキルのフロントマター、ソース、プラグイン名、ファイルパスを追加 | より詳細な情報が得られる |
| `/effort` と `/fast` をエージェントビューに追加 | 新しいセッションの開始設定を簡単に設定できる |

### ⬆️ 改善

| 変更 | 誰にどう嬉しいか |
|---|---|
| プラグインフックとワークフロースクリプトが返す値のネストレベルの上限を 28,000 に変更 | より深いネストレベルの値を扱える |
| プラグインフックがブロックできるアクションを拒否するように変更 | より安全に動作する |
| `ui.render` ツリーの `Box` または `Text` ルートに `part: { plugin }` を追加 | 正確なツリーアサーションが可能になる |
| WebFetch ページ読み取りが web 検索のように努力を選ぶように変更 | より適切な努力レベルでページを読み取れる |
| `claude plugin test` が mod の `$` メソッドへの呼び出しが 10 秒以内に応答しない場合、セッションと同様に失敗するように変更 | より正確なテスト結果が得られる |
| MCP 許可ルールが指定されたサーバーにのみ到達するように変更 | より正確な許可ルールが適用される |
| エージェントの `tools:` リストが指定された MCP サーバーのツールのみを受け取るようになる | より正確なツールリストが得られる |
| クラウドセッションと Remote Control MCP コネクタが MCP プロトコルバージョン 2026-07-28 をデフォルトでネゴシエートするように変更 | より最新のプロトコルバージョンが使用される |
| Anthropic のファーストパーティ MCP サーバーからの MCP ツールの説明とサーバーの指示が 4,096 文字で切られるのをやめ、Claude に完全に到達するように変更 | より完全な情報が得られる |
| オートモードで shell コマンドやサブエージェントを承認できなくなった | より安全に動作する |
| 終了時の resume コマンドがセッション名ではなくセッション ID で指定されるように変更 | セッション名に含まれるコマンドが実行されなくなる |
| `/btw` サイド質問が 11 分後に未回答の場合はタイムアウトエラーを返すように変更 | より適切なエラーメッセージが得られる |
| `UserPromptSubmit` フックがスキルやカスタムスラッシュコマンドが展開される前に実行されるように変更 | プロンプトをブロックするフックが埋め込まれたシェルコマンドも停止する |
| スキル自身のフロントマター `UserPromptSubmit` フックがスキルを呼び出すプロンプトの次のプロンプトで最初に実行されるように変更 | より適切なタイミングでフックが実行される |
| `turn.start` mod フックがメインループだけでなく、サブエージェントやチームメイトのターンも聞くように変更 | エージェントを区別できる |
| `/ultrareview` がリポジトリをアップロードできない場合のエラーメッセージが `git add.` を提案しないように変更 | 不要なファイルがステージングやコミットされなくなる |
| サイバーセーフガード通知が Cyber Verification Program への申請を提案しないように変更 | より適切な通知が得られる |
| セルフホステッド環境の削除がそのルーチンをすぐにオフにし、理由を各ルーチンに表示するように変更 | ルーチンの実行が失敗しなくなる |
| Claude in Slack が間違ったメッセージを修正する方法が、古いテキストを打ち消すのではなく、メッセージをその場で編集し、「Edited」ノートを追加するように変更 | より適切な修正方法が得られる |
| Claude in Slack が 100 人以上のメンバーがいるチャンネルに参加する際、紹介メッセージなしで静かに参加するように変更 | より適切な参加方法が得られる |
