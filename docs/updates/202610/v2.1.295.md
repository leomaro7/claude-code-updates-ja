# Claude Code v2.1.295 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-295

## 💡 注目ポイント

### 1. `onFailure: "block"` の追加

コマンドや HTTP フックが開始できない、タイムアウトする、または予期しないコードで終了する場合、アクションをブロックするようになりました。これにより、不正なアクションが通過するのを防ぎます。

### 2. Program Status Protocol (OSC 7501) のサポート

このプロトコルをサポートするターミナルでは、Claude Code が作業中、待機中、または完了したかどうかを表示できます。

### 3. `/copy` ピッカーへの引用テキストの追加

下書きメッセージをコピーする際、`>` マーカーなしでコピーできるようになりました。

### 4. `timeouts.upstream_ttfb_ms` のサポート

Claude apps gateway の Bedrock, Vertex, Foundry などのクラウドアップストリームで、ストリームが開始するまでの時間を制限できるようになりました。

### 5. `upstream_request_id` の追加

Claude apps gateway の `inference` 監査イベントに、Amazon Bedrock, Anthropic API などのアップストリームからのリクエスト ID が追加されました。

## 📋 変更一覧

### ✨ 新機能

| 変更 | 誰にどう嬉しいか |
|---|---|
| `onFailure: "block"` の追加 | 不正なアクションをブロックし、セキュリティを向上 |
| Program Status Protocol (OSC 7501) のサポート | ターミナルで Claude Code のステータスを表示 |
| `/copy` ピッカーへの引用テキストの追加 | 引用テキストをコピーする際、`>` マーカーなしでコピー可能 |
| `timeouts.upstream_ttfb_ms` のサポート | ストリームが開始するまでの時間を制限可能 |
| `upstream_request_id` の追加 | 監査イベントにリクエスト ID が追加され、サポートケースで役立つ |

### ⬆️ 改善

| 変更 | 誰にどう嬉しいか |
|---|---|
| MCP ツールの説明の文字数制限の変更 | 16,384 文字まで表示可能になり、より詳細な情報を得られる |
| サブエージェントのスキルプリロード数の変更 | 最大 32 スキルまでプリロード可能になり、パフォーマンスが向上 |
| Ctrl+C の動作変更 | バックグラウンドセッションで Ctrl+C を押しても `/loop` が停止しない |
| `claude agents` の動作変更 | バックグラウンドサービスが停止しても、セッションは約 1 分間継続 |
| MCP プロトコルバージョンの変更 | デフォルトで 2026-07-28 プロトコルバージョンを使用 |
| Artifact ページの背景色の変更 | 背景色が白に変更され、視認性が向上 |
| モッドがツールコールを拒否した際の表示変更 | ツールが実行され、プラグインが結果を保持していることを表示 |
| タブストップの計算方法の変更 | テキストの開始位置から計算されるようになり、インデントが正しく表示 |
| Artifact ツールのパーミッションプロンプトの変更 | テレメトリが無効な場合でも、5 つの質問でパーミッションを求める |
| スケジュールされたルーチンの実行の変更 | テレメトリが無効な場合でも、プライベートアーティファクトを公開可能 |
| 組織のモッドからのトーストの表示順序の変更 | 他のモッドのトーストよりも先に表示される |
| Claude apps gateway の動作変更 | 新しい Desktop 設定がゲートウェイのアップグレードなしで使用可能 |
| WebSocket (`ws`) MCP サーバーの動作変更 | 16 MiB を超えるメッセージは解析されず、接続が閉じられる |
| Self-hosted runner の動作変更 | `CCR_AUTO_MODE_ALLOW`, `CCR_AUTO_MODE_ENVIRONMENT`, `CCR_AUTO_MODE_SOFT_DENY` がセッションの環境に渡されなくなった |
| [Claude Tag] 設定確認カードの表示時間の変更 | 30 分間表示されるようになり、確認時間が延長 |
| [Claude Tag] 組織デフォルトの使用通知の変更 | 月 1 回まで、Claude が言及された際にのみ投稿される |

### 🐛 バグ修正

| 変更 | 誰にどう嬉しいか |
|---|---|
| `claude plugin install`, `enable`, `disable` および `marketplace add` に警告を追加 | 設定ファイルが読み込めない場合に警告が表示される |
| `claude -p` の実行が最後のターン後に開いたままの場合の stderr への出力 | 何を待っているかが stderr に表示される |
| `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` の追加 | 無人リトライモードが 429 および 529 エラーを待つ時間を制限 |
| `request-id` ヘッダーの追加 | Claude Code テレメトリの `request_id` がゲートウェイの監査ログと一致 |
| [VSCode] チャット行の追加 | ファイルを開くためのチャット行が追加され、操作性が向上 |
| [Claude Tag] チャンネルマネージャーの追加確認の追加 | カスタムロールに移動する前に確認を求め、アクセス権の喪失を防ぐ |
