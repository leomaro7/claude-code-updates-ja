# Claude Code v2.1.288 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-288

## 💡 注目ポイント

### 1. `$.ui.selection()` の追加 — テキスト選択の復元が可能に

フルスクリーンモードで最後に選択したテキストを返す `$.ui.selection()` が追加されました。選択範囲が1行のトランスクリプト内にあれば、その行も返します。これにより、選択したテキストを簡単に復元できるようになりました。

### 2. プロンプトクリアの復元機能 — Ctrl+C でクリアしたプロンプトを復元

Ctrl+C でプロンプトをクリアしても、Up キーを押すとドラフトが復元されます。貼り付けたテキストや画像も含まれます。誤ってクリアしたプロンプトを簡単に復元できるようになりました。

### 3. 最大発見数制御 — `/code-review` に `--max-findings` オプション追加

`/code-review` コマンドに `--max-findings <n>|all` オプションが追加され、発見数を制御できるようになりました。`--max-findings default` で元に戻せます。コードレビューの精度を調整できるようになりました。

### 4. セッション検索とグループ間移動 — Ctrl+F と Alt+↑/↓ の追加

Ctrl+F でセッション名を検索し、Alt+↑/↓ でグループ間を移動できるようになりました。これらは `keybindings.json` で再バインド可能です。セッション管理がより便利になりました。

### 5. 画面リーダーモードの改善 — 新しい権限モードのアナウンス

画面リーダーモードで、新しい権限モードを承認した際にアナウンスされるようになりました。Shift+Tab でもアナウンスされます。視覚障害のあるユーザーにとって、権限モードの変更がよりわかりやすくなりました。
