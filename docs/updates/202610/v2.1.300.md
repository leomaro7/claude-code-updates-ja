# Claude Code v2.1.300 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-300

## 💡 注目ポイント

### 1. 仮想テキストの追加

モッドのプロンプトデコレーションに `virtualText` を追加しました。これは、プロンプトボックスに描画されるテキストで、ドラフトや送信されたプロンプトには入りません。

### 2. OpenTelemetry イベントの拡張

`api_request` イベントに `cache_creation_5m_tokens` と `cache_creation_1h_tokens` を追加し、キャッシュの書き込みを寿命で分割しました。

### 3. エージェントトランスクリプトの表示

モッド用に `$.ui.view({ agentId })` を追加しました。これにより、指定されたエージェントのトランスクリプットをメインビューに表示できます。また、`$.ui.view({})` で戻ることができます。

### 4. 右から左へのテキストのサポート

モッドの `Text` に `dir` プロパティを追加し、Windows や VS Code のターミナルで右から左へのテキストをサポートしました。

### 5. Slack Connect チャンネルのサポート

Owner または Claude Tag 管理者は、別の組織と共有されているチャンネルで Claude in Slack が回答できるようにすることができます。デフォルトではオフになっています。

## 📋 変更一覧

### ✨ 新機能

| 変更 | 誰にどう嬉しいか |
|---|---|
| `virtualText` をモッドのプロンプトデコレーションに追加 | プロンプトボックスに描画されるテキストをドラフトや送信されたプロンプトに入れない |
| `cache_creation_5m_tokens` と `cache_creation_1h_tokens` を `api_request` イベントに追加 | キャッシュの書き込みを寿命で分割 |
| `$.ui.view({ agentId })` と `$.ui.view({})` をモッド用に追加 | 指定されたエージェントのトランスクリプットをメインビューに表示、または戻る |
| `dir` プロパティをモッドの `Text` に追加 | Windows や VS Code のターミナルで右から左へのテキストをサポート |
| Slack Connect チャンネルのサポートを追加 | Owner または Claude Tag 管理者は、別の組織と共有されているチャンネルで Claude in Slack が回答できるようにできる |

### ⬆️ 改善

| 変更 | 誰にどう嬉しいか |
|---|---|
| WebFetch を改善 | Claude にページが失敗した直後であることを伝え、再度フェッチしないようにする |
| モッドの共有を改善 | Claude がモッドのファイルをスキャンする前にキーをスキャンし、プロジェクト外のフォルダをスキャンする前に尋ねる |
| @-mentioned PDF に関する Claude 3 モデルのメモを改善 | モデルが PDF を読まずに回答する頻度を減らす |
| アーティファクトの更新を改善 | Claude が小さな変更を適用し、アーティファクトを再公開する際に 1 回の呼び出しで行う |

### 🐛 バグ修正

| 変更 | 誰にどう嬉しいか |
|---|---|
| `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` セッションが CA-bundle、tool-proxy、git TLS および git config 変数を無視するように変更 | 設定で指定された変数が無視される |
| 終了時にバックグラウンドコマンドが強制終了されるように変更 | フルスクリーンモードで以前は実行され続けていた可能性がある |
| Claude Desktop の Code タブが `forceLoginGatewayUrl` が Anthropic が運営するゲートウェイを指定している場合に管理設定を適用するように変更 | そのゲートウェイが開始時に到達可能でなければならない |
| `claude gateway` が開始時に `desktop:` ポリシーキーが Claude Desktop で使用できないゲートウェイで停止するように変更 | 以前は警告とともに開始されていた |
| `api.anthropic.com` への大規模なリクエストが gzip 圧縮を使用するように変更 | `CLAUDE_CODE_GZIP_REQUEST_BODIES=0` を設定して無効にできる |
| `claude-api` スキルが Managed Agents セッションをアーカイブまたは削除するまでそのままにしておくように変更 | セッションが削除されるまでそのままになる |
| バックグラウンドセッションが Workflow ツールの承認を通じてキャリーされたワークフローを再開するように変更 | ハンドオフファイルから実行されるのではなく、承認を通じて実行される |
| ローカルセッショントランスクリプトが各 API リクエストのシステムプロンプト、ツール、パラメータも記録するように変更 | 共有を選択したトランスクリプトがリクエストを正確に再現できる |
| `/sandbox` モードオプションが "Sandbox commands" と表示されるように変更 | "Sandbox BashTool" と表示されていた |
| Cowork クラウドセッションの `PermissionRequest` フックが `setMode` 更新を無視するように変更 | 残りの承認は適用される |
| フックの `updatedInput` が PreToolUse および PermissionRequest フックから検証されるように変更 | 不明なキーは削除され、ツールが拒否する入力は呼び出しを拒否する |
| `--sandbox` および `--no-sandbox` フラグが `claude remote-control` から削除され、効果がなくなった | どちらかを渡すとエラーで終了する。`sandbox.enabled` を設定してセッションをサンドボックス化 |
