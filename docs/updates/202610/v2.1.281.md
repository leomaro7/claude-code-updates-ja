# Claude Code v2.1.281 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-281

## 💡 注目ポイント

### 1. 新しい `desktop` ポリシーブロックのサポート

`blockReadsOutsideWorkingDirectories` と `disableBypassPermissionsMode` を含む新しい `desktop` ポリシーブロックがサポートされました。これにより、より細かい制御が可能になります。

### 2. `assume_role` の追加

Claude apps gateway Bedrock upstreams に `assume_role` が追加されました。これにより、Gateway は別の AWS アカウントで IAM ロールを引き受けることができます。

### 3. Amazon Bedrock guardrail の適用

`guardrail: {id, version}` が Bedrock upstreams に追加され、すべてのリクエストに Amazon Bedrock guardrail を適用できます。

### 4. テレメトリの改善

`telemetry.resource_attributes` が追加され、Claude Desktop と `/login` セッションのテレメトリに固定ラベルを付けることができます。

### 5. フルスクリーンモードの改善

`/skills`, `/mcp`, `/plugin` のインストール済みリストにスクロールバーが追加され、マウスオーバー時に表示されます。
