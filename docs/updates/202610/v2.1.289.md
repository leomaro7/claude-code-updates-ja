# Claude Code v2.1.289 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-289

## 💡 注目ポイント

### 1. プラグインのパフォーマンス改善

大規模なファイルがプラグインコードペインでより速く開くようになりました。これにより、大規模なファイルを取り扱う際に待ち時間が短縮され、作業効率が向上します。

### 2. プラグインの安定性向上

複数のプラグイン関連のバグが修正されました。これにより、プラグインのインストール、評価、更新がより安定し、エラーが発生する可能性が低減されます。

### 3. セキュリティルールの適用範囲拡大

Bashのdeny/askルールが、環境変数プリフィックスの拡張値を持つコマンドに対して適切に適用されるようになりました。これにより、セキュリティルールの適用範囲が拡大され、より多くのコマンドが制御下におかれることになります。

### 4. 新しいエージェント機能の追加

`agent.spawn`が追加され、チームメイト間でエージェントを生成できるようになりました。また、プラグインフックイベント間で一意のエージェントIDが使用されるようになり、アイドルおよび待機状態が`$.agent.list()`で利用可能になりました。

### 5. ユーザーインターフェースの改善

モッドのバンドやペインが描画に失敗した際、モッドの名前と描画されなかったことを示すメッセージが表示されるようになりました。これにより、開発者がエラーの原因をより容易に特定できるようになります。
