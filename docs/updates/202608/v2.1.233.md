# Claude Code v2.1.233 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-233

## 💡 注目ポイント

### 1. GitLab マージリクエスト URL サポートの追加

`--worktree` フラグと `claude agents` ビューに GitLab マージリクエスト URL サポートが追加されました。これにより、マージリクエストは `!N` として表示されます。

### 2. アプリゲートウェイ設定 `forward_user_identity` の追加

Anthropic アップストリームに `forward_user_identity` アプリゲートウェイ設定が追加されました。これにより、サインインしたユーザーの ID がヘッダーとして送信され、ゲートウェイの後ろにあるプロキシがユーザーごとの支出を属性化できます。

### 3. Bash ツールコマンドのメモリ cgroup サポートの追加

Linux 上で Bash ツールコマンドのメモリ cgroup サポートが追加されました（`CLAUDE_CODE_TOOL_MEMORY_LIMIT`）。これにより、ランナウェイビルドがセッションを停止するのを防ぐことができます。

### 4. WebFetch セッション URL キャッシュ TTL の環境変数 `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` の追加

WebFetch セッション URL キャッシュの TTL を設定する環境変数 `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` が追加されました（デフォルトは変更なし：15 分）。

### 5. クラウドセッションの改善

クラウドセッションが環境がシャットダウン中に Claude が許可プロンプトを待っているときに稀に失われたとマークされる問題が修正されました。
