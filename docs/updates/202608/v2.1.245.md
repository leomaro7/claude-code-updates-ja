# Claude Code v2.1.245 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-245

## 💡 注目ポイント

### 1. Linux ディストリビューションでのクラッシュ修正

glibc 2.44 を搭載した Linux ディストリビューション（例：Arch Linux、CachyOS、Fedora Rawhide）で、起動時にクラッシュする問題が修正されました。これにより、これらの環境で安定して利用できるようになりました。
