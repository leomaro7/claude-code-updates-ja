# Claude Code v2.1.248 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-248

## 💡 注目ポイント

### 1. `--restricted` モードの追加 — セキュリティを強化

`--restricted` オプション（または `CLAUDE_CODE_RESTRICTED=1`）を追加し、コマンドやコードを実行する組み込みツールや `WebFetch` を削除し、ファイルツールを作業ディレクトリ内に保持し、`bypassPermissions` を拒否し、ユーザー、プロジェクト、ローカル設定ファイルを無視するようにしました。

### 2. `experimental.cacheTtl` の追加 — エージェントごとのプロンプトキャッシュTTLを設定

エージェントのフロントマターに `experimental.cacheTtl`（`"5m"` または `"1h"`）を追加し、サブエージェントのTTL設定が設定されていない場合に使用されるエージェントごとのプロンプトキャッシュTTLを設定できるようにしました。

### 3. `claude self-hosted-runner --client-label <label>` の追加 — ランナーの登録ラベルをオーバーライド

`claude self-hosted-runner --client-label <label>`（または `SELF_HOSTED_RUNNER_CLIENT_LABEL`）を追加し、ランナーが登録するラベルをオーバーライドできるようにしました（デフォルトはホスト名）。

### 4. サーバー管理設定の診断の追加 — 設定の読み込み失敗時に警告を表示

設定の読み込みに失敗したときにスタートアップ警告を表示し、`/doctor` と `/status` ラインで読み込み失敗の理由や取得されなかった理由（Bedrock/Vertex/サードパーティプロバイダー、カスタムの `ANTHROPIC_BASE_URL`）を説明するようにしました。

### 5. `/usage-credits` の追加 — Enterprise組織がAWS Marketplace、セルフサーブEnterprise、Enterpriseトライアルを通じて請求される場合、メンバーが管理者に高い使用量制限を要求できるように

Enterprise組織がAWS Marketplace、セルフサーブEnterprise、Enterpriseトライアルを通じて請求される場合、メンバーが管理者に高い使用量制限を要求できるように`/usage-credits`を追加しました。
