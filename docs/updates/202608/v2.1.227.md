# Claude Code v2.1.227 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-227

## 💡 注目ポイント

### 1. 機能フラグの評価がユーザーのプランに応じて正しく行われるよう修正

セッションが有効期限切れのログイントークンで開始された場合、ユーザーのサブスクリプションティアを考慮せずに機能フラグが評価され、Maxプランのユーザーに誤ってFableの使用クレジットを有効にするよう促す可能性がありました。この問題が修正されました。

### 2. GitHubホストランナーで`allowed_non_write_users`が有効な場合、`claude-code-action`ですべてのBashコマンドが失敗する問題を修正

GitHubホストランナーで`allowed_non_write_users`が有効な場合、`claude-code-action`ですべてのBashコマンドが失敗する問題を修正しました。

## 📋 変更一覧

### 🐛 バグ修正

| 変更 | 誰にどう嬉しいか |
|---|---|
| セッションが有効期限切れのログイントークンで開始された場合、ユーザーのサブスクリプションティアを考慮せずに機能フラグが評価される問題を修正 | Maxプランのユーザーが誤ってFableの使用クレジットを有効にするよう促されることがなくなる |
| GitHubホストランナーで`allowed_non_write_users`が有効な場合、`claude-code-action`ですべてのBashコマンドが失敗する問題を修正 | Bashコマンドが正しく動作するようになる |
| `/tui`で最初のメッセージよりも前に巻き戻された会話が戻ってくる問題を修正 | 意図しない会話の復帰がなくなり、正しい会話の流れが保たれる |

### ⬆️ 改善

| 変更 | 誰にどう嬉しいか |
|---|---|
| スラッシュコマンドメニューの改善：選択した行のみが青色でマークされ、一致する文字は太字で表示され、絵文字やアクセント付きの名前はグリフを保持する | メニューの可読性が向上し、選択がしやすくなる |
| パフォーマンスの改善：ファイルが見つからない場合のサジェスチョンやメンションサイズチェックでのイベントループの停止が減少 | 操作がよりスムーズになり、レスポンスが向上する |
