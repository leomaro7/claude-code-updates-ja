# Claude Code v2.1.224 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-224

## 💡 注目ポイント

### 1. セルフホステッド環境の追加 — チームプランとエンタープライズプランで自前のマシンやコンテナをセッション実行場所に

`claude self-hosted-runner` により、チームプランとエンタープライズプランで自前のマシンやコンテナをウェブ、モバイル、デスクトップセッションの実行場所にすることができます。

### 2. `archive` プラグインソースの追加 — ZIP ファイルを HTTPS 経由でインストール

`archive` プラグインソースにより、ZIP ファイルを HTTPS 経由でインストールできるようになりました。git や npm は不要で、オプションで SHA-256 ピンニングも可能です。

### 3. キャンセルと確認のステップの追加 — コマンドのテキストを変更するペーストの削除時に

コマンドのテキストを変更するペーストを削除する際に、キャンセルと確認のステップが追加されました。

### 4. `ANTHROPIC_BEDROCK_REGION_PREFIX` 環境変数の追加 — Bedrock で特定のクロスリージョン推論プロファイルを優先

`ANTHROPIC_BEDROCK_REGION_PREFIX` 環境変数により、Bedrock で特定のクロスリージョン推論プロファイルを `AWS_REGION` 由来のものよりも優先できます。

### 5. `crossSessionInbound` と `dialogExpiry` 設定の追加 — セッション間でメッセージを送受信

`crossSessionInbound` と `dialogExpiry` 設定により、セッション間でメッセージを送受信できるようになりました。

### ⬆️ 改善

| 変更 | 誰にどう嬉しいか |
|---|---|
| フルスクリーンモードの改善 | 繰り返しの圧縮を超えて完全な圧縮前の履歴をスクロールバックで保持 |
| Remote Control の改善 | 接続失敗時に永続的な失敗インジケーターと再接続ショートカットを表示 |

### 🐛 バグ修正

| 変更 | 誰にどう嬉しいか |
|---|---|
| 長いプロジェクトパスの解決 | 共有されたサニタイズされたプレフィックスの下で別のプロジェクトのセッションディレクトリに解決されないように |
| `SendMessage` の修正 | 実際には失敗していたチームメイトの受信箱への書き込みが「メッセージが送信されました」と報告されないように |
| サンドボックスファイルシステムの否定エントリの修正 | トレーリングスラッシュで書かれたエントリが Linux と macOS でサイレントにバイパス可能にならないように |
| サンドボックス違反の詳細の修正 | 拒否されたファイルやネットワークアクセスとその理由がクラウドに見えるようになる |
| その他のバグ修正 | 安定性と使いやすさの向上 |

### 📝 その他

| 変更 | 誰にどう嬉しいか |
|---|---|
| 200-subagent-per-session の spawn cap の削除 | 長時間実行されるセッションが新しいエージェントを拒否しないように |
| マネージド設定の変更 | 組織の設定が変更されていない場合、再ログインや組織の切り替え後に承認プロンプトが再表示されないように |
| フィードバック調査のトランスクリプト共有の変更 | ユーザーの同意を得て、最後のリクエストのモデル設定もアップロードするように |
| Bash ツールの説明の変更 | コマンド出力がユーザーではなくモデルに表示されることを常に記載するように |
| リコールされたペーストのプレースホルダ番号の変更 | 入力に受け入れられたときに再番号付けされるように |
| Remote Control の変更 | コンパクト化や `/resume` 後に新しいセッションが作成されたときに、古いサーバーセッションをアーカイブするように |
| [VSCode] 拡張機能の修正 | Remote Control が接続に失敗した後も接続済みとして表示されないように |
| セッションの再開の修正 | ユーザーがオフにした後でもサイレントに Remote Control を再接続しないように (`--resume`、SDK ホスト、VS Code 拡張機能) |
| [VSCode] セッションの修正 | `remoteControlAtStartup` が明示的に有効化されたときに honor されるように |
