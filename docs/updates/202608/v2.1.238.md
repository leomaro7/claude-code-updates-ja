# Claude Code v2.1.238 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-238

## 💡 注目ポイント

### 1. `keybindingFlavor` 設定の追加 — Ctrl+W の動作を Bash のように変更可能

`keybindingFlavor` 設定を `"readline"` に設定すると、プロンプトでの Ctrl+W が前の空白まで削除するようになります。デフォルト (`"classic"`) は変更されません。この設定は、Bash のような動作を好むユーザーにとって便利です。

### 2. プラグインマーケットプレイスでの `headersHelper` コマンド — HTTP ヘッダーの生成

URL マーケットプレイスやカタログエントリで `headersHelper` を使用すると、カタログや同一オリジンアーカイブのフェッチ用の HTTP ヘッダー（例：短期有効トークン）を生成するコマンドが実行されます。これは、プラグインのインストールや更新時にのみ実行されます。

### 3. `claude self-hosted-runner` の `--defer-shutdown-max-min` オプション — セッションの終了を遅延

`--defer-shutdown-max-min <minutes>` オプションを追加し、SIGTERM 受信時に指定された分数だけ接続セッションを継続し、その後終了します。これは、長時間のセッションを維持したいユーザーに有益です。

### 4. メモリ使用量の改善 — 長時間の対話型セッションでの無限メモリ成長を修正

長時間の対話型セッションでの無限メモリ成長を修正し、サブエージェントツールの結果が最近の表示ウィンドウから離れると解放されるようになりました。これにより、メモリ使用量が安定します。
