# Claude Code v2.1.246 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-246

## 💡 注目ポイント

### 1. Bash 許可ルールの起動警告

サブコマンドの前にワイルドカードを含む Bash 許可ルール（例：`Bash(git * main)`）に対して、サブコマンドの前に挿入されたオプションにもマッチするため、起動警告を追加しました。

### 2. `/permissions` に自動モードタブを追加

自動モードの分類ルールを確認および編集するための `/permissions` に自動モードタブを追加しました。

### 3. ターンの完了時間を表示

ターンの完了時間をターンの期間の最後に表示するようになりました（例：`✻ Sautéed for 23s · done 6:05 PM`）。

### 4. フルスクリーンモードの改善

フルスクリーンモードでターミナルをリサイズし、下にジャンプした後、次のキープレスまで空のトランスクリプトを表示する問題を修正しました。

### 5. 長い単一行のレンダリング改善

diff に非常に長い単一行（例：base64 文字列）が含まれている場合のトランスクリプトの重大な遅延を修正し、そのような行はマーカー付きで切り詰めてレンダリングされるようになりました。
