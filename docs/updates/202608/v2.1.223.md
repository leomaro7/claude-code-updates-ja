# Claude Code v2.1.223 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-223

## 💡 注目ポイント

### 1. オーナーワイルドカードエントリの追加 — GitHub 組織下のすべてのマーケットプレイスレポを一括で許可またはブロック

`strictKnownMarketplaces` と `blockedMarketplaces` マネージド設定にオーナーワイルドカードエントリ (`"owner/*"`) を追加しました。これにより、GitHub 組織下のすべてのマーケットプレイスレポを一括で許可またはブロックできるようになりました。

### 2. 制限されたサブエージェントモデルの警告 — ワークフローエージェント、フォークされたスキル、スラッシュコマンド、または再開されたバックグラウンドエージェントが要求したサブエージェントモデルが制限されている場合の警告

制限されたサブエージェントモデルが要求された場合、親モデルが代わりに実行される際に警告が表示されるようになりました。これにより、意図しないモデルの使用を防ぐことができます。

### 3. `/teleport` ヒントの追加 — クラウドセッションでローカルに続行する方法を示すヒント

クラウドセッションで `/teleport` ヒントが表示されるようになりました。これにより、`claude --teleport <session id>` を使用してローカルで続行する方法が示されます。

### 4. Bash パーミッションバイパスの修正 — クラフトされたコマンドがパーミッションチェックから一部を隠せないように

Bash パーミッションバイパスを修正し、クラフトされたコマンドがパーミッションチェックから一部を隠せないようにしました。これにより、セキュリティが向上します。

### 5. ワークフロースクリプトの動的 `import()` の修正 — ワークフローサンドボックス外でコードを実行できなく

ワークフロースクリプトが動的 `import()` を使用してワークフローサンドボックス外でコードを実行できなくなりました。これにより、サンドボックスのセキュリティが強化されます。
