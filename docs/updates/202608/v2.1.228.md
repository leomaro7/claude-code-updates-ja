# Claude Code v2.1.228 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-228

## 💡 注目ポイント

### 1. クロスセッションメッセージの改善 — リモートコントロールセッションでのコミュニケーションがスムーズに

クロスセッションメッセージの送信者がインラインで表示されるようになり、リモートコントロールセッションでは送信者としてリモートコントロールセッション名が表示されるようになった。これにより、異なるマシン間でのコミュニケーションがより明確になり、混乱が減少する。

### 2. Vertex AI クレデンシャルの改善 — エラー時の待ち時間が短縮

期限切れや欠落した Google Cloud クレデンシャルの場合、数分間の再試行ではなく、数秒以内に失敗するようになった。これにより、クレデンシャル関連のエラーに対する待ち時間が大幅に短縮され、ユーザーの不満が軽減される。
