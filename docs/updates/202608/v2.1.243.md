# Claude Code v2.1.243 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-243

## 💡 注目ポイント

### 1. `/usage` にループの詳細を追加

`/usage` コマンドにループごとの実行回数、トータルトークン数、1回あたりのトークン数、最後の実行日時を追加しました。これにより、ループが暴走したり、チャットが多い `/loop` タスクを簡単に見つけることができます。

### 2. `modelPicker` 設定の追加

`modelPicker` 設定を追加し、`/model` ピッカーをカスタマイズできるようになりました。任意のモデルID（Vertex/Bedrock IDを含む）を順序付けし、ラベルを付けてリストに追加または置き換えることができます。

### 3. プロンプトキャッシュのTTL設定の追加

`promptCacheTtl` と `subagentPromptCacheTtl` 設定を追加し、APIキーとクラウドプロバイダーのユーザーがメイン会話で1時間のプロンプトキャッシュを保持し、サブエージェントは5分に設定できるようになりました。

### 4. モデル価格設定の追加

`modelPricing` 管理設定を追加し、組織が契約したモデルごとのレートと割引倍率を `/cost`、ステータスライン、テレメトリコスト数字に使用できるようになりました。

### 5. キーレスサインインの追加

`/login` → Anthropic Console にキーレスサインインを追加し、APIキーを使用できない組織でもサインインできるようになりました。
