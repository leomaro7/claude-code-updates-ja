# Claude Code v2.1.229 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-229

## 💡 注目ポイント

### 1. Remote Control セッションの継続が可能に

`claude remote-control --continue` コマンドで、直近の Remote Control セッションを再開できるようになりました。これまではセッションが終了すると再開できなかったため、作業の継続性が向上します。

### 2. セルフホステッドランナーでサーバー提供のフックが利用可能に

セルフホステッドランナーセッションでも、マネージド環境と同様にサーバー提供の Claude Code フックがサポートされるようになりました。これにより、セルフホステッド環境でも同じ機能が利用可能になります。

### 3. 長時間の思考中に SSE キープアライブピングが追加

長時間の思考中にゲートウェイストリーミング応答に SSE キープアライブピングが追加され、Vertex や Bedrock の上流でのアイドルタイムアウト切断が防止されます。

### 4. プラグインマーケットプレイスにコマンドソースが追加

ローカルコマンド（IDE など）がプラグインディレクトリを印刷し、セッションごとに再解決され、再起動なしで適用されます。`mode: "link"` で使用されます。

### 5. `ListAgents` でリモートコントロールセッションの接続状態が表示

`ListAgents` で、切断されたリモートコントロールセッションが `offline` としてマークされ、クラウドセッションが `cloud` としてラベル付けされるようになりました。
