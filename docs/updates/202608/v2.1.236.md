# Claude Code v2.1.236 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-236

## 💡 注目ポイント

### 1. `ANTHROPIC_DEFAULT_MODEL` 環境変数追加 — セッション開始時のデフォルトモデルを設定

この環境変数を設定すると、新規セッションが開始する際のデフォルトモデルを指定できます。ただし、`/model` コマンドで選択したモデルはこれを上書きし、再起動後も保持されます。

### 2. `notify_when_idle` オプション追加 — アイドル時に通知を送信

`SendMessage` コマンドに `notify_when_idle` オプションを追加しました。これにより、別のセッションがアイドル状態になった際に一度だけ通知を送信できます。ポーリングは行いません。

### 3. Sandbox のワイルドカード read-deny ルール改善 — macOS でより厳格な制御

macOS の Sandbox において、ワイルドカード read-deny ルール（例: `**/.env`）が許可された読み取り領域内で優先され、一致するディレクトリの内容をカバーするようになりました。また、拒否されたファイルをリネームしてもバイパスできなくなりました。

### 4. フルスクリーンレンダラーの改善 — 起動失敗後もクラシックレンダラーにフォールバック

フルスクリーンレンダラーが一度起動に失敗しても、それ以降はクラシックレンダラーにフォールバックするようになりました。以前は毎回起動に失敗して終了していました。

### 5. `/model` ピッカーの改善 — ターミナルの高さに合わせてモデルを表示

`/model` ピッカーがターミナルの高さに合わせてモデルを表示するようになりました。以前はターミナルの高さを超えて表示されていました。
