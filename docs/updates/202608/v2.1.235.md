# Claude Code v2.1.235 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-235

## 💡 注目ポイント

### 1. スペルチェック機能の追加

オプション設定 `spellcheck` を追加し、プロンプト入力中にスペルミスを下線で表示する機能を実装しました。`aspell`, `hunspell`, または `ispell` がインストールされていれば、入力中にスペルミスを検出します。

これまでの課題: プロンプト入力中のスペルミスに気づきにくい  
ユーザーへの嬉しさ: 入力ミスをリアルタイムで検出できるため、誤字脱字を減らせる  
注意点・ヒント: この機能はオプションであり、`spellcheck` 設定を有効にする必要がある

### 2. バックグラウンドセッションのメモリ・CPU使用量改善

クラウドセッション（`/ultrareview` や `/autofix-pr` など）がバックグラウンドで実行中の場合、イベントストリームが再スキャン・再レンダリングされないように改善しました。これにより、メモリとCPUの使用量が改善されます。

これまでの課題: バックグラウンドセッションがリソースを過剰に消費していた  
ユーザーへの嬉しさ: バックグラウンドセッションの実行中でも、他の作業がスムーズにできるようになる  
注意点・ヒント: この改善はバックグラウンドセッションにのみ適用される

### 3. パーミッションダイアログの改善

パーミッションダイアログの表示テキストと「次回から聞かない」オプションが、実際に付与される権限と常に一致するように改善しました。また、内容を完全に表示できない場合は「次回から聞かない」オプションが表示されないようになりました。

これまでの課題: パーミッションダイアログの表示と実際の権限が一致しない場合があった  
ユーザーへの嬉しさ: パーミッションの付与内容が明確になり、誤った権限付与を防げる  
注意点・ヒント: この改善により、一部のダイアログの表示内容が変更される

### ⬆️ 改善

| 変更 | 誰にどう嬉しいか |
|---|---|

| コンテキスト制限エラーメッセージの改善 | 自動圧縮がオフの場合を示し、`/config` で再有効化を指示 |
