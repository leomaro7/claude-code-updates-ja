# Claude Code v2.1.239 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-239

## 💡 注目ポイント

### 1. コスト見積もりに US オンリー推論プレミアムを反映

データレジデンシーワークスペースの `/cost` コマンド、ステータスライン、`--max-budget-usd` オプションで表示されるコスト見積もりに、USオンリー推論の1.1倍プレミアムが反映されるようになりました。これにより、USオンリーワークスペースの実際のコストをより正確に見積もることができます。

### 2. フルスクリーンレンダラーの提供拡大

Bedrock、Vertex、Foundryなどの以前は除外されていたセットアップでも、フルスクリーンレンダラーの提供を開始しました。これらのセットアップでの新規インストールは、フルスクリーンモードで開始されます。

### 3. `/claude-api upgrade` コマンドの追加

Pythonプロジェクトを`anthropic` 0.xから1.xへ移行するための`/claude-api upgrade`コマンドを追加しました。また、1.x用のスキルのPythonリファレンスを更新しました（タイムアウトは`anthropic.Timeout`を使用）。

### 4. クラウドセッションでのプラグインの同期

クラウドセッションで、`claude.ai`から同期されたプラグインは`name@synced`として表示され、`claude plugin enable/disable <name>@synced`で操作できます。同期されたプラグインは、同じ名前のローカルプラグインを上書きしません。

### 5. 使用制限メッセージの改善

月間支出制限に達した際に表示される使用制限メッセージに、セッションまたは週間制限のリセット時期も表示されるようになりました。
