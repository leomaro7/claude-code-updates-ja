# Claude Code v2.1.237 アップデートまとめ

> 出典: https://code.claude.com/docs/en/changelog#2-1-237

## 💡 注目ポイント

### 1. 組み込みの "Concise" 出力スタイルの追加 — 結果重視の簡潔な出力

従来のクラウドの出力は、前置きや説明が長く、結果にたどり着くまでに時間がかかる
ことがありました。新たに追加された "Concise" 出力スタイルは、結果を先頭に
表示し、前置きや説明を省略します。ただし、処理の徹底さは従来通りです。
`/config` の Output style で選択できます。

このスタイルは、結果をすぐに確認したいユーザーや、簡潔な出力を好むユーザーに
特に嬉しい変更です。情報量は減りますが、必要な結果に素早くアクセスできます。
